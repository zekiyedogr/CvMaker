# CvMaker

CvMaker is a CV creation application that helps users create, manage, and customize professional resumes.

The project consists of three main components:

- **Backend:** Provides API services, authentication, database operations, and PDF generation.
- **Mobile Application:** Allows users to manage their profiles and CVs through a mobile interface.
- **Web Application:** Provides access to CV management features through a web interface.

## Project Modules

### Backend
- Node.js
- Express.js
- Microsoft SQL Server
- JWT Authentication
- PDF Generation with Puppeteer

### Mobile Application
- React Native
- JavaScript

### Web Application
- Web frontend for accessing CvMaker services.

## Project Purpose

The main purpose of CvMaker is to simplify the CV creation process by allowing users to organize their personal information, education, work experience, skills, and other professional details in one place.

Users can manage their CV information and generate professional CV documents in PDF format.
